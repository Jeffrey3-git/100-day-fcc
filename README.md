# ⚡ 100-Day freeCodeCamp Streak Celebration

A dynamic, interactive showcase page celebrating a **100-day daily coding streak on freeCodeCamp**. Built to showcase progress moving beyond basic tutorials into full-stack development, feature engineering, and real-world project builds.

![Project Status](https://img.shields.io/badge/Status-Completed-success)
![Streak](https://img.shields.io/badge/FCC%20Streak-100%20Days-orange)

## Features

* **Animated Hero Counter:** Dynamic number count-up animation on page load.
* **Theme Switcher:** Dark/Light mode toggle with `localStorage` persistence and system color scheme detection.
* **Preloader Animation:** Custom loading overlay with automated status transitions.
* **Interactive Skill Badges:** Visual breakdown of current tech stack proficiencies.
* **Milestone Timeline:** Interactive vertical timeline tracing the journey from Day 1 to Day 100.
* **Responsive Layout:** Optimized for mobile, tablet, and desktop viewports.

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3 (Custom Properties & Flexbox/Grid), Vanilla JavaScript (ES6+)
* **Styling:** Dynamic CSS Themes (`data-theme`), Animations, and Responsive Web Design
